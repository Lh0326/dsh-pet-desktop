# 助手小乖 · dsh-pet-desktop

> 桌面版 DeepSeek Harness (dsh) + 生态皮肤系统 + 个人定制桌宠"小乖"
> 对小乖说话 = 对 dsh 下指令。

## 功能路线

- 🖥️ **桌面版 dsh**：Tauri 2 壳，托盘常驻，一键启动本地 dsh Web UI
- 🎨 **皮肤系统**：复用 [dsh-web-ui](https://github.com/zhu1090093659/dsh-web-ui) 皮肤中心生态
- 🐾 **小乖桌宠**：个人定制精灵图桌宠，8 状态联动 dsh 会话（空闲/思考/工作/需确认/完成/聆听/说话/互动）
- 🎙️ **语音入口**：FunASR 本地识别 → 直发 dsh → edge-tts 播报（开发中）
- 📱 **手机端**：原生 App 远控小乖/发指令（预留）
