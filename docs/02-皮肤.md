## 方案

按规划复用 [zhu1090093659/dsh-web-ui](https://github.com/zhu1090093659/dsh-web-ui)（2220★）的聚合包方案：一个包 `@linxin666/dsh-web-ui-all` 装齐全部功能插件与皮肤（10 款皮肤：Windows XP Luna / Blue Fantasy / Whale Song / Harbor 等，支持试穿+一键应用）。

## 安装过程（留痕）

```sh
cd F:\github\dsh
pnpm dsh plugin --profile web add @linxin666/dsh-web-ui-all
```

### 踩坑1：ERR_PNPM_IGNORED_BUILDS（README 已预警）
pnpm 拒绝运行 `cloudflared` / `cpu-features` / `ssh2` 三个包的构建脚本，安装失败。
**修复**：`C:\Users\28675\.dsh\profiles\web\pnpm-workspace.yaml` 的 `allowBuilds` 三项改 `true`（dsh 已生成占位模板，填 true 即可），重跑安装。

### 踩坑2：ssh2 原生编译耗时 14 分钟
ssh2 的加密绑定需要 MSVC 现场编译（308 个函数）。一次性开销，属正常。顺带验证了我们装的 VS Build Tools 在第三方构建里也工作正常。

### 安装结果
profile `web` 的 bundles：`@deepseek-ai/dsh-base` + `@deepseek-ai/dsh-web-app` + `@linxin666/dsh-web-ui-all@0.1.12`

## 与本项目的关系

- 皮肤中心跑在 dsh Web UI 内，我们的 Tauri 壳只是加载它——零耦合，壳不用做任何事
- dsh-web-ui-all 自带一个"鲸鱼桌宠"（dsh-pet），它是**页面内**桌宠；我们阶段3的"小乖"是**系统级透明窗**桌宠，两者不冲突（可同时开，后期可在设置里加开关）
