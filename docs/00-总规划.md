# 助手小乖 · 总规划

> 仓库：Lh0326/dsh-pet-desktop ｜ 创建：2026-08-15 ｜ 状态：🚧 阶段1开发中

## 项目是什么

**助手小乖**是一个 DeepSeek Harness (dsh) 桌面增强套件，一句话：

> 桌面版 dsh（Tauri 2）+ 生态皮肤系统 + 个人定制桌宠"小乖"——小乖不只是宠物，它是 dsh 的统一语音入口：对它说话 = 对 dsh 下指令，它替你跑腿、向你汇报。

## 三阶段路线图

### 阶段1：桌面版（Tauri 2 壳）
- [ ] Tauri 2 项目初始化（Rust + WebView2）
- [ ] 自动拉起本地 dsh Web UI 服务（复用本机 Node.js，工作目录 F:\github\dsh 源码检出）
- [ ] 主窗加载 http://127.0.0.1:3080
- [ ] 系统托盘常驻（最小化到托盘、右键菜单、退出）
- [ ] 单实例保护（防多开导致会话日志损坏——社区已知的并发 bug）
- [ ] 产出：`docs/01-桌面版.md`

### 阶段2：皮肤系统
- [ ] 桌面壳的 dsh profile 中安装 dsh-web-ui 皮肤中心（zhu1090093659/dsh-web-ui，2220★）
- [ ] 安装皮肤包（@linxin666/dsh-skins 等 8 款）
- [ ] 验证 Tauri WebView2 下 CSS 注入/试穿/应用全流程可用
- [ ] 产出：`docs/02-皮肤.md`

### 阶段3：小乖桌宠（核心）
- [ ] **窗体**：独立透明置顶小窗（Tauri multiwindow），可拖拽、穿透设置
- [ ] **动画**：精灵图序列帧渲染器，8 状态机（见素材规范）
- [ ] **状态联动**：订阅 dsh 会话事件（空闲/思考/工作/需确认/完成 → 动画切换）
- [ ] **互动**：双击唤起主窗、抚摸/投喂反应动画
- [ ] **语音链路**（先按键说话，后唤醒词）：
  - ASR：FunASR/SenseVoice 本地（4060 GPU 加速，中文优先）
  - 链路：小乖聆听 → ASR 转文字 → 作为 prompt 发送 dsh 会话 → 流式结果 → edge-tts 播报（说话态动画）
- [ ] **服务层**（为手机端预留）：本机 HTTP/WebSocket 服务，暴露 /pet/control、/dsh/message 等接口
- [ ] 产出：`docs/03-桌宠.md`、`docs/04-语音.md`

### 阶段4（预留，不在本期）：手机端原生 App
- 经局域网（后续可 frp 公网，已有 119.91.145.142 frp 经验）控制小乖互动、向 dsh 发指令、接收结果
- 阶段3的服务层接口协议即为此设计，届时不返工

### 贯穿性交付物：桌宠 DIY 工作流水线（硬性要求）
本项目不只产出"小乖"一个成品，还要沉淀一套**可复用的桌宠 DIY 流水线**，任何人基于它可快速产出其他形象的定制桌宠：
- **素材规范**（已有 `素材规范-小乖.md`，将泛化为形象无关的通用版）：状态清单、视频要求、生成提示词模板
- **一键加工脚本**（`scripts/` 下持续固化）：视频 → 黑边检测裁除 → 水印消除 → 抠白 → 主体裁切 → 归一 → 精灵图+meta.json 全自动
- **数据驱动渲染**：桌宠渲染器只认 meta.json（状态名/帧数/fps/精灵图路径），不硬编码任何"小乖" specifics——换一套 assets 目录即换宠物
- **DIY 指南**（阶段3末产出 `docs/05-DIY流水线.md`）：从"我想做一个XX宠物"到跑起来的完整步骤

### 留痕原则（硬性要求）
- 每个步骤有 git commit；每个阶段有 docs/ 文档；关键决策记录进本文档"技术选型决策记录"
- 素材加工的中间产物（检测出的边框厚度、水印坐标等参数）写入 meta.json，保证过程可追溯、可复现

## 技术选型决策记录

| 决策点 | 选择 | 理由 |
|---|---|---|
| 桌面框架 | Tauri 2 | 体积小、内存低、透明置顶窗（桌宠必需）；Rust 桌宠已有先例（dsh-plugin-pet-rs） |
| 皮肤 | 复用 dsh-web-ui 皮肤中心 | 生态最成熟（2220★），不自研换肤，精力留给桌宠 |
| 桌宠素材 | 精灵图序列帧 | 工具链成熟，AI 生图可切入，个人定制门槛最低 |
| ASR | FunASR/SenseVoice 本地 | 中文最强、轻量、4060 加速、离线隐私 |
| TTS | edge-tts | 免费、音色多、零 GPU 占用 |
| 语音入口 | 桌宠为统一入口 | 对小乖说话 = 对 dsh 下指令 |
| 手机端 | 原生 App（后期） | 局域网服务层先定协议 |
| 文档 | 同仓 docs/ 每阶段一篇 | 持续完善的项目需要文档跟代码同步 |
