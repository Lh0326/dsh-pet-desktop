# 小乖桌宠素材规范 + 生成提示词模板

> 你需要做的：拿生活照片作参考图，用即梦/豆包/任何支持"参考图+提示词"的图像生成器，按本文模板批量生成 8 组图，交给 Claude 切帧入仓。

## 一、总原则

1. **角色一致性是生命线**：所有 8 组图必须像"同一只小乖"。每次生成都带同一张参考照片，且提示词里的外形描述一字不改。
2. **透明背景**：生成器若支持"透明底/抠图"直接用；不支持就生成**纯白背景**，我这边自动抠图。
3. **风格建议**：Q版三头身/吉祥物风最容易保持一致性，也最省切帧功夫。写实风对一致性要求极高，不推荐。

## 二、状态清单（8 组）

| # | 状态 (state id) | 触发场景 | 动画描述 | 帧数建议 |
|---|---|---|---|---|
| 1 | `idle` 空闲 | dsh 无会话/等待输入 | 站立呼吸、缓慢眨眼、偶尔左右看 | 4-8 帧 |
| 2 | `thinking` 思考 | 模型推理中 | 托腮/歪头，头顶冒问号或省略号 | 4-6 帧 |
| 3 | `working` 工作 | 工具调用/代码执行 | 搬砖/敲键盘/卷袖子快节奏动作 | 6-8 帧 |
| 4 | `confirm` 需确认 | dsh 等待权限确认 | 挥手吸引注意、感叹号气泡 | 4-6 帧 |
| 5 | `done` 完成 | 任务成功结束 | 跳跃庆祝、撒花、比心 | 4-8 帧 |
| 6 | `listening` 聆听 | 麦克风收音中 | 身体前倾、竖耳/靠近麦克风、声波涟漪 | 4-6 帧 |
| 7 | `speaking` 说话 | TTS 播报中 | 嘴部开合、表情生动、手势比划 | 6-8 帧 |
| 8 | 互动反应（三个子状态） | 拖拽/抚摸/投喂 | 拖拽(僵硬紧张)、抚摸(眯眼享受)、投喂(开心咀嚼) | 各 3-4 帧 |

## 三、图片硬性规格

| 项 | 要求 |
|---|---|
| 格式 | PNG（无损） |
| 单帧尺寸 | **512×512px**（正方形，角色居中占画面 70-80%） |
| 背景 | 透明（或纯白 #FFFFFF 由我抠） |
| 朝向 | 正面或 3/4 侧面，全状态统一 |
| 命名 | 生成时不用管，交给我后统一切帧命名 |

**每组交付形式（二选一，推荐 A）**：
- A. 每状态一段短视频/GIF（2-3 秒循环）→ 我抽帧
- B. 每状态 4-8 张连续动作图 → 我直接拼精灵图

## 四、生成提示词模板（直接抄，替换【】内内容）

### 4.1 角色锚定段（每组提示词的固定开头，一字不改）

```
一个Q版三头身吉祥物角色"小乖"，根据参考照片的形象设计：圆润可爱的造型，
大大的眼睛，柔和的【头发/毛色：如棕色短发】配色，穿着【服装：如白色连帽卫衣】。
保持与参考照片完全一致的角色特征、配色和服装。扁平插画风，线条干净，
明快柔和的配色，全身照，角色居中占画面70%，纯白背景，无阴影投射地面。
```

> 把【】里改成你照片的实际特征后**固定下来**，后续所有生成用同一段。

### 4.2 各状态动画段（拼接在锚定段后面）

```
【idle】     小乖自然站立，轻微上下呼吸起伏，缓慢眨眼，表情平静放松，双臂自然下垂。
【thinking】 小乖歪着头托腮思考，头顶漂浮着三个小圆点省略号，眼睛向上看，一脸认真。
【working】  小乖卷起袖子奋力搬砖，双手抱着一块砖块快步走，表情专注有干劲，动作幅度大。
【confirm】  小乖举起右手用力挥动，急于引起注意，头顶一个黄色感叹号气泡，表情着急。
【done】     小乖开心地跳跃庆祝，双手举高比心，周围散落彩色纸屑星星，笑容灿烂。
【listening】小乖身体前倾凑近，侧头竖起耳朵认真听，嘴边有淡淡的声波涟漪线条。
【speaking】 小乖嘴巴张开正在说话，表情生动眉飞色舞，一只手抬起做讲解手势。
【互动-拖拽】小乖被拎着悬空，四肢僵硬下垂，表情紧张无辜。
【互动-抚摸】小乖眯起眼睛享受地歪头，脸红满足，头顶冒出爱心。
【互动-投喂】小乖双手捧着食物大口咀嚼，腮帮子鼓鼓的，幸福表情。
```

### 4.3 视频/动作序列生成附加段（如果用视频抽帧）

```
2秒循环动画，动作流畅连贯，帧间变化均匀，角色位置固定在画面中心不移动，
适合抽取为精灵图序列帧，循环无缝。
```

## 五、操作流程

1. 选 1 张最有代表性的生活照片作参考图（光线好、正面、特征清晰）
2. 填好 4.1 的锚定段（问 Claude 帮你润色也行）
3. 锚定段 + 各状态段，逐状态生成（每个状态多生成几次挑最好的）
4. 放到 `素材原始件/` 文件夹（按状态建子文件夹：idle/、thinking/……）交给 Claude
5. Claude 负责：抠图（纯白→透明）、尺寸归一 512×512、抽帧、拼精灵图、写帧元数据 JSON、入仓 `assets/pet/`
