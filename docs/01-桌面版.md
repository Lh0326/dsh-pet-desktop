## 架构决策（留痕）

1. **dsh 以源码方式托管**：不打包 dsh 进安装包，壳直接 `cmd /C pnpm dsh web` 于 `F:\github\dsh`。理由：用户是 dsh 学习者/二开者，源码检出是主资产；打包内置运行时是"普通用户版"的路线，以后可加。
2. **端口探测代替 PID 管理**：dsh 默认 3080。启动前先 `TcpStream::connect` 探测，已有服务（无论谁起的）直接复用，避免社区已知的多实例会话损坏 bug。
3. **先等待页后跳转**：主窗初始加载壳自己的等待页（鲸鱼动画+状态文案），Rust 侧后台线程拉起 dsh，就绪后 `emit("dsh-ready")`，前端整页 `location.href` 跳转。避免 WebView 直接指向 3080 时白屏/连接失败闪烁。
4. **关窗=隐藏到托盘**：`CloseRequested` 拦截 + `prevent_close`，托盘"退出"才真正结束（顺带 kill 我们拉起的 dsh 子进程）。
5. **CREATE_NO_WINDOW**：Windows 下 spawn dsh 不弹控制台黑框。

## 踩坑记录（留痕）

- **create-tauri-app 在非空目录直接失败**（exit 1 无提示）：在空临时目录生成后拷入仓库。
- **Tauri tray 需要 feature**：`tauri = { version = "2", features = ["tray-icon"] }`，默认不开，报 `could not find tray in tauri`。
- **`Command::creation_flags` 是 Windows 专属**：用 `#[cfg(windows)]` 分平台封装，非 Windows 直接 spawn。
- **`try_wait` 需要 `&mut Child`**：`guard.as_mut()` 而非 `as_ref()`。
- **winget 装完 VS BuildTools 提示"Restart PC"**：实测无需重启即可链接（MSVC 14.44 就位）。
