### host 半区（src/index.ts + routes.ts）
- session/event 驱动状态机：turn/step(思考)/tool(搬砖)/turn-end(庆祝) → 10 态动画

### client 半区（src/client.ts）
- 单图集渲染（鲸鱼娘同款）：backgroundImage/Size 恒定，动画只改 position（x=帧列 y=状态行）→ **切换零残留帧**
- 帧循环：rAF + meta 驱动；循环态绝对时钟取模相位（零节奏抖动）；暂时态播一轮即回落
- 交互：拖拽（鲸鱼娘铁律：move 中绝不改写锚点）、单击摸头、悬停面板（贴身零间隙+400ms缓冲）、投喂/隐藏/召回（低调"乖"小圆钮）
- 工程防御：跨 bundle 单例守护（window 令牌）、精灵图 decode 解码门、图集失效橙框占位、视口钳制

### 修复战记（每条都是实测实锤，方法论留痕）
| 症状 | 根因 | 手段 |
|---|---|---|
| 拖拽漂移/挪一点飞很远 | move 中更新锚点基准→位移按步幅累加 | 鲸鱼娘铁律：锚点只在 down 设置 |
| 分身（两只可交互小乖） | createPortal 节点存活于 body+模块级令牌跨 bundle 失效 | 去 portal + window 令牌单例 |
| 重影（视觉残像） | 大图换图解码空窗+WebView2 合成器不同步 | 单图集+decode 门+GPU 合成层隔离 |
| 切换扁平化/残留帧 | backgroundImage/Size/Position 三属性非原子更新 | 单图集：切换只动 position |
| idle 循环抽搐 | 循环重置截断小数相位累计抖动 | 绝对时钟取模相位 |
| 隐身可交互 | 补丁脚本静默失败→atlasBroken 未定义→组件崩溃 | 补齐定义+断言式补丁流程 |
| 托盘重启无效 | kill 只杀 cmd 不杀 node 树+release 未重编 | taskkill /T + 端口清理 + 重编 release |

**关键工具**：CDP（Chrome DevTools Protocol）自动化——无头 Edge + WebSocket 直连，程序化注入鼠标事件、16ms DOM 幽灵监控、console 错误捕获。多个"猜不出来"的 bug 全靠它实锤。
